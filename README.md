# Netflix Movies & TV Shows Data Analysis

## 📌 Project Overview

This project analyzes a Netflix Movies and TV Shows dataset using Python to understand content distribution, ratings, release trends, movie durations, and the differences between Movies and TV Shows.

## 🛠️ Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## 🔍 Analysis Performed

- Dataset exploration
- Data cleaning
- Missing value analysis
- Duplicate analysis
- Movies vs TV Shows comparison
- Content distribution by ratings
- Movie duration analysis
- Release year analysis
- Top 10 analysis
- Data visualization
- Comparison of Movies and TV Shows over the years

## 📊 Visualizations

The project includes visualizations such as:

- Bar charts
- Pie charts
- Histograms
- Line charts
- Multiple subplot comparisons

## 🎯 Key Skills

- Data Cleaning
- Data Manipulation
- Data Aggregation
- GroupBy
- Data Visualization
- Python Data Analysis
